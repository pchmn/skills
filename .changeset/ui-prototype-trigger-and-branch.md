A validated prototype is now required for any UI that adds a control, a screen state or on-screen information, not only a new screen or layout. `to-tickets` asks whether it is made on the ticket's branch or at implementation, `implement` stops for `/prototype` or starts from that branch and reverts the prototype before the pull request, and `code-review` reports a UI built without a prototype.
