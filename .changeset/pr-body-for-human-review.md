The pull request template that **`setup-matt-pocock-skills`** writes is now made for a human reviewing an agent's code. It drops "Type of Change" and the folded "Technical Details", and adds Risk of Merging (whether a revert undoes it, what breaks if it is wrong, what no check covers), a Code Summary view of the change's shape, and a Review Guide: the few places to read closely, what to skim, and the choices the ticket left open. **`implement`** notes those choices while it builds and lists them in the body.
