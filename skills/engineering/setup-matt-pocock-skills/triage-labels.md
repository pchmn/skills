# Triage Labels

The skills speak in terms of three canonical triage states and two categories. This file maps those roles to the actual label strings used in this repo's issue tracker.

| Role              | Label in our tracker | Meaning                                         |
| ----------------- | -------------------- | ----------------------------------------------- |
| `needs-triage`    | `needs-triage`       | An idea not yet grilled into a ticket           |
| `ready-for-agent` | `ready-for-agent`    | The body is an agent brief, every gap settled   |
| `wontfix`         | `wontfix`            | Will not be actioned                            |
| `bug`             | `bug`                | Something is broken                             |
| `enhancement`     | `enhancement`        | New feature or improvement                      |

Every issue carries one state and one category, both set by whoever creates it. An issue written after a conversation that settled it is born `ready-for-agent`.

When a skill mentions a role (e.g. "apply the AFK-ready triage label"), use the corresponding label string from this table.

Edit the "Label in our tracker" column to match whatever vocabulary you actually use.
